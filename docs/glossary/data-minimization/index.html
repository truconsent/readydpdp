Glossary

Data Minimization

Collecting and retaining only the personal data genuinely necessary for the disclosed purpose — no more, "just in case."

Data minimisation is the discipline of collecting only what a specific, disclosed purpose genuinely requires, and not retaining it beyond that purpose's useful life. It shows up operationally in shorter sign-up forms, tighter field-level justification during product design, and defined retention or deletion triggers rather than indefinite storage "in case it's useful later." A DPIA's necessity-and-proportionality test is largely a formal check on this principle for any specific high-risk processing activity under review.
