Glossary

Collection Point

The specific touchpoint — a form, screen, script, or API — where personal data is originally captured from a Data Principal.

A collection point is any specific touchpoint where personal data enters an organisation's systems from a Data Principal — a website signup form, a mobile app screen, a call-centre script, a physical KYC form, a partner data feed. Every collection point should have a corresponding notice and consent mechanism appropriate to what it collects. Mapping every collection point comprehensively — including ones added informally by product teams over time — is the specific purpose of our Customer Data Journey Registry methodology.
