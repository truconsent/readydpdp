Data Fiduciary Accuracy Obligation

The duty to ensure personal data used to make a decision affecting a Data Principal, or disclosed to another Fiduciary, is accurate and complete.

Where personal data is likely to be used to make a decision affecting a Data Principal, or is to be disclosed to another Data Fiduciary, the Act requires the Data Fiduciary to ensure the completeness, accuracy and consistency of that data. This obligation is easy to overlook because it doesn't map neatly to a single UI flow the way consent does — it requires operational discipline around data quality, particularly for data feeding automated decisions or shared with partners.
