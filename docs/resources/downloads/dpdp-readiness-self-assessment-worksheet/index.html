DPDP Readiness Self-Assessment Worksheet

Answer each question with the option that best matches your organisation today, note its level number, then average across all eight to get a directional DPDP Readiness Level.

Download .csv

This is a self-scored worksheet, not a substitute for an independent Gap Assessment — but it will give you and your leadership team a defensible, directional starting point in about ten minutes.

1. Who owns data protection compliance at your organisation?

  1. No one — it has never been formally discussed — Level 0
  2. Leadership is aware DPDPA applies, but no owner is assigned — Level 1
  3. A Gap Assessment or equivalent has been done and work has started — Level 2
  4. A named owner exists, even if fractional, with documented policies — Level 3
  5. A named owner runs recurring audits and reports to leadership — Level 4
  6. Data protection maturity is used as a competitive differentiator — Level 5

2. How well do you know what personal data you actually collect?

  1. No inventory exists — we would be guessing — Level 0
  2. An informal, undocumented understanding exists — Level 1
  3. Partial inventory covers some products or teams, not all — Level 2
  4. A documented, field-level inventory (e.g. a DPDR) exists — Level 3
  5. The inventory is kept current as products change — Level 4
  6. The inventory feeds privacy-by-design review for every new feature — Level 5

3. How are consent flows structured today?

  1. No privacy policy update or consent flow review since the Act — Level 0
  2. A single blanket "I agree" checkbox covers everything — Level 1
  3. Some products have updated flows; others have not — Level 2
  4. Purpose-specific consent is standard across products — Level 3
  5. Consent mechanisms are audited against purpose linkage regularly — Level 4
  6. Consent architecture is interoperable with the Consent Manager model — Level 5

4. How are Data Principal rights requests handled?

  1. No defined process exists — Level 0
  2. Requests would go to a general inbox with no SLA — Level 1
  3. An informal contact person exists, process is undocumented — Level 2
  4. A documented process exists with a target SLA — Level 3
  5. SLA performance is consistently met and reported to leadership — Level 4
  6. Rights fulfilment is a benchmarked, continuously improved process — Level 5

5. What is the state of your vendor / Data Processor contracts?

  1. Not reviewed — most predate the DPDPA — Level 0
  2. Awareness that contracts need review, no action taken — Level 1
  3. Some contracts under review, not systematically — Level 2
  4. DPAs have been reviewed and substantially remediated — Level 3
  5. Vendor risk tiering and annual DPA refresh is standard practice — Level 4
  6. Vendor diligence is proactive, screened before onboarding begins — Level 5

6. How prepared are you for a personal data breach?

  1. No breach response plan exists — Level 0
  2. Awareness that a plan is needed, nothing built yet — Level 1
  3. A draft plan exists but is untested — Level 2
  4. A plan exists and has been reviewed by the relevant owner — Level 3
  5. The plan has been tested via tabletop exercise or a real incident — Level 4
  6. Breach readiness is reviewed and refreshed on a regular cadence — Level 5

7. How does your board or leadership engage with data protection?

  1. Never discussed at board or leadership level — Level 0
  2. Discussed once, reactively, after an external trigger — Level 1
  3. Occasional updates, no regular cadence — Level 2
  4. Leadership receives updates at key programme milestones — Level 3
  5. Board receives regular, structured compliance reporting — Level 4
  6. Board actively uses compliance posture in strategic decisions — Level 5

8. How would you handle a new product launch or AI feature today?

  1. Privacy is not considered as part of product decisions — Level 0
  2. Privacy is considered only if someone happens to raise it — Level 1
  3. Privacy review happens after launch, not before — Level 2
  4. New launches are screened for DPDPA impact before shipping — Level 3
  5. A DPIA process is applied consistently for higher-risk launches — Level 4
  6. Privacy-by-design is embedded from the earliest design stage — Level 5

Scoring guide

For each question above, note the level number of the option that best matches your organisation today. Average your answers across all 8 questions and round to the nearest whole number for a directional DPDP Readiness Level.

Average scoreApproximate level
0.0 – 0.99Level 0 — Unaware
1.0 – 1.99Level 1 — Aware
2.0 – 2.99Level 2 — Developing
3.0 – 3.99Level 3 — Defined
4.0 – 4.99Level 4 — Managed
5.0 – 5.99Level 5 — Optimised

This worksheet is a directional self-assessment, not a substitute for an independent DPDP Gap Assessment.
